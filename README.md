# ⚙️ VoteBharat - Backend

Welcome to the **Backend** of **VoteBharat**, a robust and secure **Online Voting System** developed using the **MERN Stack**. This backend handles authentication, election management, vote processing, and ensures data security and integrity.

---

## 🚀 Tech Stack

### **Backend Technologies**
- **Node.js** - JavaScript runtime for scalable backend development
- **Express.js** - Lightweight framework for handling API requests
- **MongoDB & Mongoose** - NoSQL database for storing election data
- **JWT Authentication** - Secure login and session management

### **Deployment & Hosting**
- **Render** - Hosting for backend services
- **GitHub** - Version control and collaboration

---

## 🔑 Features of Backend

✅ **Admin & Voter Authentication** - Secure JWT-based authentication system  
✅ **Election Management** - Create, edit, and delete elections dynamically  
✅ **Candidate Handling** - Manage candidates and their details  
✅ **Vote Processing** - Secure and tamper-proof vote submission   
✅ **API Security** - Middleware protection against unauthorized access  
✅ **Error Handling** - Well-structured API error responses

## 🎯 How to Run Backend Locally

### **Prerequisites**
Ensure you have the following installed:
- Node.js (v16+)
- MongoDB (Local or Atlas)
- Git

### **Clone the Repository**
```bash
 git clone -b backend https://github.com/LohithReddyy/VoteBharat.git
 cd VoteBharat/backend
```

### **Install Dependencies**
```bash
 npm install
```

### **Set Up Environment Variables**
Create a `.env` file in the root directory and add the following:
```env
 PORT=5000
 MONGO_URI=mongodb+srv://your-db-url
 JWT_SECRET=your-secret-key
```

### **Run the Server**
```bash
 npm start
```
The backend will now be running on `http://localhost:5000`.
